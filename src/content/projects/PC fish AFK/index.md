## 前言
我在 Steam 市集上面看到這個遊戲，一開始覺得養魚很好玩，而且在專心養了接近3天後我擁有了第一隻神話魚，讓我興奮不已。但我也因此開始思考，是否還有更輕鬆的方式可以來養魚，而非我一直守在螢幕前注意他的繁殖時間，因此我就與 AI 聯手寫程式，最終成功讓電腦可以自動養魚，也因此養出了許多稀有的魚。


## 畫面辨識
本專案放棄了傳統「固定螢幕座標點擊」的自動化作法，改採電腦視覺的動態範本匹配技術。

* **動態定位機制**：使用 OpenCV 與 PyAutoGUI 針對遊戲 UI 元素（如加號圖示、標題列、特定稀有度標籤）預先建立特徵圖檔。程式執行時動態掃描當前螢幕畫面，比對信心度並計算出匹配區域的中心座標。
* **抗解析度與位移干擾**：彈性因應視窗拖動、微小位移或介面自適應排版，避免因單一座標偏差導致腳本卡死或誤觸其他區域。
* **相對錨點精準捲動**：以「選擇魚隻」標題列作為畫面垂直定位的絕對錨點，動態計算選單可捲動區域後再觸發滑鼠滾輪事件，確保選單翻頁時的視野一致性。
* **空間過濾與防重複機制**：對畫面中匹配出的多組相同特徵進行去重複計算，剔除因範本比對半徑過近而產生的重疊偵測框；並透過 Y 軸相對高度閥值動態跳過前排魚隻，精準鎖定指定排數目標。

## 掛機步驟說明

自動化掛機主流程採週期性迴圈控制，單次繁殖的執行步驟如下：

1. **優先級掃描**：依序載入稀有度優先清單（稀有 $\rightarrow$ 高級 $\rightarrow$ 普通），嘗試在魚缸中尋找可配對的目標。
2. **開啟魚隻選單**：點擊左側加號按鈕開啟選取介面，若未偵測到加號則標記異常並進入重試機制。
3. **動態翻頁與配對尋找**：
   * 在目前畫面中掃描符合目標稀有度的特徵。
   * 若數量不足兩隻，則以錨點位置向下滾動選單，最多滾動 5 次。
   * 若翻遍選單皆無法湊齊兩隻同稀有度的魚，則點擊關閉按鈕，切換至下一個優先級重複搜尋。
4. **雙目標選取**：
   * 鎖定目標稀有度後，過濾出第三排的兩組獨立魚隻座標。
   * 透過 DirectInput 模擬真實滑鼠事件，依序移動並點擊第一隻與第二隻魚，並在動作間加入延遲以確保遊戲客戶端成功註冊事件。
5. **發起繁殖**：點擊主繁殖按鈕發送指令，進入結算過場動畫。
6. **封包監聽與數據更新**：在過場動畫期間切換至日誌監聽模式，讀取背景即時攔截到的 API 資料，解析出本次繁殖得到的魚種代碼與稀有度。
7. **確認結果並進入休眠**：點擊結算畫面的確認按鈕完成收尾，隨後進入 7 分鐘的休眠等待遊戲體力回復，時間結束後自動喚醒進入下一輪。

## 魚種稀有度辨識

傳統視覺辨識在遊戲結算畫面上極易受到發光粒子、動態特效及相近色系的干擾，導致稀有度誤判。本專案改由網路傳輸層直接獲取伺服器權威數據。

### 1. 封包攔截架構
* **TLS 解密與代理架構**：以 Fiddler Classic 作為本機 HTTPS 中間人代理（MITM Proxy），安裝本機根憑證以解密客戶端與遊戲伺服器間的 TLS 連線。
* **網域過濾與效能最佳化**：限制代理僅監聽遊戲 API 網域 `gapi.nanoocompany.com`，並將 Session 緩存上限壓至 100 筆，避免長時間掛機導致記憶體洩漏。
* **事件驅動日誌導出**：在 FiddlerScript 的 `OnBeforeResponse` 生命週期中加入過濾邏輯：
  * 當網域為 `gapi.nanoocompany.com` 且 Response Body 包含 `breedCount` 關鍵字時觸發。
  * 自動執行 `utilDecodeResponse()` 解壓縮與還原編碼。
  * 將內含最新繁殖資訊的原始 JSON 字串即時寫入本機 `fish_log.txt`。

### 2. 數據解析與終端機統計表
Python 腳本在點擊繁殖後，自動讀取 `fish_log.txt` 的最新行並進行 JSON 反序列化：
* 取出 `data.level`（稀有度 1～5）與 `data.type`（魚種模型代碼）。
* 將 `level` 映射至對應名稱（1: 普通、2: 高級、3: 稀有、4: 傳說、5: 神話）。
* 即時累加各等級的歷史培育數量，並在終端機格式化輸出統計總表：

```text
========================================
 📊 本次掛機繁殖成果總表
========================================
  普通        : 12 隻
  高級        : 8 隻
  稀有        : 3 隻
  傳說        : 1 隻
  神話        : 0 隻
----------------------------------------
  總計繁殖數  : 24 隻
========================================
```

## 未來努力方向
### 全背景無阻斷自動化
目前腳本依賴作業系統層級的滑鼠模擬（pydirectinput），執行期間會搶佔使用者滑鼠控制權。未來計畫嘗試 Windows API 的 SendMessage / PostMessage 或是將遊戲環境遷移至虛擬機 / 無周邊容器環境，實現背景靜默操作，讓自動化運作時不干擾日常電腦使用。

### 同稀有度辨識
進一步逆向分析 API 中的魚種詳細數據（如 fish 唯一 ID、成長值、親代組合關係）。不再僅依賴前端畫面標籤湊對，改由發送前即時評估最佳配對組合，嚴格鎖定高純度基因或最高稀有度親代，大幅提高產出傳說與神話等級魚隻的機率。
