# MY Blog

這是我的個人作品集空間，融合了**資訊安全**、**程式開發**與**興趣**的紀錄。這不只是一個網頁，更是我學習歷程的數位副本。

## 🛠️ 製作與設計亮點
* **極致效能**: 基於 **Astro** 靜態生成框架，確保內容能秒速載入並擁有極佳的 SEO 表現。
* **UI/UX 設計**: 完全透過 **Canva** 打造簡約且具科技感的深色視覺原型，追求直覺的操作體驗。
* **視覺風格**: 核心背景採用自定義的**星空流星效果**，搭配 **Tailwind CSS** 的玻璃擬態（Glassmorphism）與響應式佈局。
* **動態維度**: 整合 **GitHub API**，讓網站 Footer 的「最後更新時間」與專案 Commit 同步，實現自動化數據呈現。

## 🏗️ 製作過程
1. **概念發想**: 於 Canva 繪製首頁與時間軸原型，確定以「星空探索」與「互動時間軸」為視覺語彙。
2. **架構選型**: 選用 Astro 框架，利用其 **Content Collections** 功能系統化處理大量的 Markdown 作品集與圖片優化。
3. **核心開發**:
   - 開發 `About Me` 三欄式過濾系統，實作標籤、類別與年份的交集篩選邏輯（Vanilla JS）。
   - 設計響應式導航系統與手機版分頁切換（Tabs）功能，確保在行動端也能流暢閱讀。
4. **自動化部署**: 串接 Vercel 進行 CI/CD 持續整合，只要推送至 GitHub，網站即自動完成構建。

## ✍️ 新增貼文教學 
> **⚠️ 警告：路徑不對會導致圖片 404，請務必嚴格執行以下流程：**
1. **建立目錄**: 於 `/src/content/projects` 下新增一個資料夾 (例如：`New-Project`)。
2. **存入檔案**: 將該文章的 `.md` 檔與內文所需的所有照片直接放入上述資料夾。
3. **處理主要縮圖 (重要)**: 若要在 Projects 列表頁正常顯示主圖，需**額外複製一份該照片**到 `public/projects/` 下對應的資料夾中（若資料夾不存在請手動建立），這樣才能確保路徑完全正確。
4. **檢查 Frontmatter**: 確認 MD 檔頂部的 YAML 設定如下（注意 image 路徑）：
```markdown
title: "你的專案名稱"
date: "2026.02.20"
category: "資訊安全"
tags: ["CTF", "Python"]
image: "projects/圖片所在的資料夾名稱/圖片檔名"
```
